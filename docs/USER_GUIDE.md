# Using QuizX Studio

**ProudGeonZer0QuizX · Upgrade 1.0**

## Sign in and activate

1. Open the workspace’s `/login` page. Hosts and Players use the same form. Ask the workspace operator for your temporary credentials; there is no self-registration.
2. Enter your username and password. The eye button shows or hides the password. **Studio guide** explains the two roles; **Activation guide** covers first login.
3. On first login, your current username is displayed. Choose a **different** unique username (3–32 letters, digits, or underscores) and enter the new password twice. Usernames are case-insensitive and stored lowercase. Passwords are case-sensitive: 12+ characters, uppercase, lowercase, and a digit, at most 72 UTF-8 bytes.
4. Select **Activate account**. Your account’s role determines the dashboard. Next time, use the new credentials. Never share passwords in chat or screenshots.

## Host: create → publish → assign → review

1. **Overview** shows your game/assignment counts and recent games. A new studio intentionally starts empty. Choose **Create game**.
2. Set a title and optional instructions. Add question text, two to four answers and a points value (default 10). Mark the circle beside the **one correct answer**. Use the arrows to reorder questions, or add/remove questions and options. To save a title-only draft, remove the blank question first.
3. **Save draft** to continue later in **My games**, or **Publish game** when ready. The server validates the game; a stale draft opened in another tab must be reopened before saving.
4. Open the published game → **Manage assignments**. Check one or more Players, choose **Assign selected**, and confirm. The list below shows assigned Players and whether each is ready, in progress or completed. Returning to the page refreshes progress. A Player can activate after being assigned.
5. Use **Players** to search the directory and check activation status. Use **Results** to see final scores for your games. Passwords and other Hosts’ games/results are not available here.
6. To discard an unassigned published game, **Unpublish** it first, then **Delete draft** and confirm. An assigned game stays locked: create a new game for a revised quiz.

## Player: play an assigned game

1. **My games** shows only quizzes assigned to you. If none are listed, wait for your Host. Return to the page or select **Refresh** after an assignment.
2. Open a game, read the instructions and points, then **Start game**. Choose one answer per question. An open attempt can be resumed, but unsaved choices do not survive a page reload.
3. When every question is answered, select **Submit answers**. Review or confirm the final submission. Only one submission is allowed; the server calculates your score.
4. The result shows points earned, possible points, number correct and submission time. Revisit it in **My results**. If your connection failed during submission, reopen the game or history before retrying; a finalized attempt cannot be submitted twice.

## Settings, phones, and sign-out

- **Settings:** verify your current password, then change your username, password, or both. Leave optional fields blank to keep them unchanged. Other sessions for this account must sign in again after a change.
- On a narrow screen, open **Workspace menu** beside your profile for navigation and **Log out**. Separate users should use separate devices, browser profiles or private contexts, not tabs in the same profile.
- After inactivity or absolute session expiry, sign in again. Repeated failed attempts may require a 15-minute wait. There is no public password reset in this release: contact the trusted operator privately if locked out.
